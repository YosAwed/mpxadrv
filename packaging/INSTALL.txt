mpxadrv macOS binary package
============================

This binary is dynamically linked against Homebrew's mdxmini and
FluidSynth. Install those first:

  brew install mdxmini fluid-synth

Then put bin/mpxadrv and bin/mpxadrv-player on your PATH, or run
them by absolute path.

Prefer a source install when possible:

  brew tap YosAwed/mpxadrv
  brew trust YosAwed/mpxadrv
  brew install mpxadrv

SoundFonts are not included; see README.md for an optional SC-55 bank.
